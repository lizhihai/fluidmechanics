v₃9.20m/s p₁42.9kPa

喷射高度 h₁3.0m
泵进口淹没深度 h₂6.0m

重力加速度 g9.80m/s²
进口段损失系数 k₁5.0×v₁²/2g
出口段损失系数 k₂12.0×v₂²/2g

计算过程随参数实时代入

1
连续性方程：先定速度分配
v₁ = v₃(d₃/d₁)² = 0.250 v₃
v₂ = v₃(d₃/d₂)² = 0.563 v₃
2
两段压头损失折算到 v₃
hf,0-3 = k₁v₁²2g + k₂v₂²2g = 4.109 v₃²2g = 17.77 m
3
0—0 与 3—3 截面间机械能守恒
Nqmg = v₃²−v₀²2g + (z₃−z₀) + p₃−p₀ρg + hf,0-3
取 v₀≈0、p₃=p₀、z₃−z₀=h₁，整理为关于 v₃ 的三次方程：
N = [ K·v₃²2 + g·h₁ ] · ρ v₃ πd₃²4
其中 K = 1 + k₁(d₃/d₁)⁴ + k₂(d₃/d₂)⁴ = 5.109
11.29 v₃³ + 129.89 v₃ = 10000
单调递增，唯一正根： v₃ = 9.21 m/s
4
0—0 与 1—1 截面间求进口压力
v₁²−v₀²2g + (z₁−z₀) + p₁−p₀ρg + hf,0-1 = 0
z₁−z₀ = −h₂，hf,0-1 = k₁v₁²/2g，故
p₁ − p₀ = ρg [ h₂ − (1+k₁)·v₁²2g ] = 42930 Pa

趋势：调它，v₃ 怎么变横轴为所选参数

当前例题基准

边调边想四个关键点

三个截面放进一个方程。0—0（液面）、1—1（泵进口）、3—3（喷口）用同一条机械能守恒方程串联。泵的输入功率以 N/(qmg) 的形式进入方程，量纲是长度，即压头。
管径决定速度分配。由 vA = 常数，速度与直径平方成反比。本题 d₃/d₁=0.5，所以 v₁ 只有 v₃ 的 1/4；喷口最细，流速最高。
功率与速度是三次关系。动能 ∝ v²，质量流量 ∝ v，相乘得 N ∝ v³。忽略提升高度时，功率翻倍只让喷速升到 21/3≈1.26 倍。把 N 从 10 kW 拖到 20 kW，本例 v₃ 由 9.21 升到 11.8 m/s，约 1.28 倍——比一次方增长慢得多。
抬得越高，喷得越慢。同样的功率要先支付 g·h₁ 这份"重力账单"，剩下的才用于加速。把 h₁ 拖大，v₃ 明显下降；反之把 h₁ 拖到 0，v₃ 达到最大。
进口压力可能变成负表压。p₁−p₀ = ρg[h₂ − (1+k₁)v₁²/2g]，淹没深度 h₂ 提供静压，流速与进口段损失消耗静压。若把 h₂ 拖小或把 d₃ 拖大，p₁ 会转为负值——工程上意味着泵进口有汽蚀风险。
损失系数很"贵"。k₁、k₂ 每增加 1，相当于多消耗一份速度头。本题 k₂=12 时出口段损失约占总损失的 92%，所以缩短管路、减少弯头比单纯加大功率更有效。
依据教材第四章例 4-13 的方程与数据重建，公式与题设损失系数（5v₁²/2g、12v₂²/2g）一致。
原题答案：v₃≈9.2 m/s，p₁−p₀=42930 Pa（ρ=1000，g=9.8）。本页按 π 精确值求解，得 v₃=9.21 m/s、p₁−p₀≈42911 Pa，与书上取整结果吻合。
